# Bob Session Screenshots

This directory holds PNG screenshots of IBM Bob task session summaries, captured manually after each task completes.

## How to add screenshots

1. After a task session completes in IBM Bob, take a screenshot of the session summary panel.
2. Save it as `session-task-<N>.png` where `<N>` is the task number (e.g. `session-task-1.png`).
3. Commit the PNG alongside any code changes for that task.
